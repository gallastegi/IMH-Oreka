# Rendimiento economico futuro

Este documento deja delimitado el alcance futuro. La iteracion actual implementa
solo `Rendimiento operativo`.

## Fuentes pendientes

Para calcular rendimiento economico harian falta fuentes validadas de:

- ingresos;
- facturacion;
- costes;
- gastos;
- presupuestos;
- margen;
- cobros.

Ninguna de estas magnitudes se inventa ni se muestra como cero en el MVP.

## Relacion con Rendimiento operativo

La arquitectura operativa deja preparado:

- grano persona + proyecto + tarea + mes;
- planificado vs real;
- trabajo sin planificacion;
- capacidad y ocupacion;
- diagnosticos e informes.

El modulo economico futuro deberia apoyarse en esa trazabilidad, pero debera
mantener separadas las fuentes economicas y las fuentes de horas.
